折腾了几天，这个博客终于上线了。

## 为什么搭一个自己的博客

理由其实很简单：**想有一个属于自己的地方，安静地记录一些东西**。写在社交平台上的内容，总感觉是「别人家」的；而一个自己的域名、自己掌控的博客，才真正属于自己。

## 技术栈

这个站点的搭建方式非常轻量：

- **Jekyll** —— 一个静态博客生成器，文章用 Markdown 写就行
- **GitHub Pages** —— 免费托管，push 上去自动构建发布
- **纯 CSS** —— 没有用任何前端框架，主题颜色用几个 CSS 变量就能换

```bash
# 本地预览（装了 Ruby 之后）
bundle exec jekyll serve
```
